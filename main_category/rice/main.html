リュウジのバズレシピ｜豚丼レシピまとめ

このページでは、YouTube「リュウジのバズレシピ」で紹介された豚丼レシピをまとめています。

🐖 シン・豚丼

材料（1人前）

  • ご飯：200g
  • 豚バラ肉：120g
  • 玉ねぎ：30g
  • 卵黄：1個
  • 砂糖：小さじ1＋小さじ2
  • 水：大さじ1/2
  • 醤油：大さじ1＋小さじ1
  • 酒：大さじ1/2
  • みりん：大さじ1/2

作り方

1. フライパンに砂糖小さじ1＋水小さじ1.5を入れ、カラメル化する。
2. 調味料と玉ねぎを入れて沸かし、少し煮詰める。
3. 豚バラ肉を入れて絡める。
4. ご飯に盛り、卵黄をのせて完成。

🐖 最高傑作豚丼

材料（1人前）

  • 豚バラブロック：150g
  • ご飯：200g
  • 長ネギ：6cm
  • 醤油：大さじ1.5
  • みりん：大さじ1.5
  • 酒：大さじ1
  • 砂糖：小さじ1
  • ハイミー：4振り
  • 中華あじ：小さじ1.5

作り方

1. 長ネギを細切りにする。
2. 豚バラブロックを1cm弱に切る。
3. 豚肉を焼き、ぬるま湯で油抜きする。
4. 中華あじで豚スープを作る。
5. 調味料を入れて煮詰め、タレを作る。
6. ご飯に盛り、ネギをのせて完成。

🐖 基本の豚丼

材料（1人前）

  • 豚バラ肉：100g
  • 玉ねぎ：1/4個
  • 生姜：3g
  • 鰹節：3g
  • ご飯：200g
  • 水：60cc
  • みりん：大さじ2
  • 醤油：小さじ4
  • 砂糖：小さじ1/3
  • 味の素：3振り

作り方

1. 玉ねぎをくし切りにする。
2. 鰹節をレンジで40秒加熱し、ほぐす。
3. 調味料と玉ねぎを鍋で5分煮る。
4. 豚肉を入れ、さらに5分煮る。
5. ご飯に盛り、紅生姜をのせて完成。
